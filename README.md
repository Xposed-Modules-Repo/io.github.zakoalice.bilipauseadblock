# B站暂停广告屏蔽（BiliPauseAdBlock）

屏蔽哔哩哔哩在暂停视频时弹出的广告，以及左下角「3秒后将展示广告 / 取消」的倒计时提示。
模块在功能开关处关闭整条暂停广告流程：不请求广告、不显示倒计时、不弹广告面板，也不会影响其它广告位。

- 适用：哔哩哔哩 Android 客户端 9.17.0（其它版本未逐一测试）
- 环境：LSPosed（Legacy API，`xposedminversion 93`）或兼容的免 root 框架（如 NPatch / LSPatch）；Android 7.0+
- 作用域：`tv.danmaku.bili`
- 当前版本：1.0（versionCode 1）

## 安装

1. 下载并 APK 安装
2. 在框架里启用模块，作用域勾选 **哔哩哔哩（`tv.danmaku.bili`）**
3. **强行停止**哔哩哔哩，再重新打开（开关在进程启动时读取，不重启不生效）
4. 随便打开一个视频并暂停：不应再出现倒计时条，等待数秒也不会弹出广告

想临时停用：在框架里禁用本模块并强停哔哩哔哩即可，不需要卸载。

## 验证是否生效

```bash
adb logcat -s BiliPauseAdBlock:V
```

强停并重开哔哩哔哩后看到 `hooks installed` 表示模块已注入；暂停时出现
`OFF ... key=dd_ad_pausedpage_enable` 之类的日志，说明开关已被拦截。日志同时会进入框架的模块日志。

## 已知边界

- 只处理暂停广告。开屏、信息流、视频贴片、评论区广告不受影响。
- 针对 9.17.0 定位开关，B 站大版本更新后可能需要重新适配。
- 未做框架隐藏。若客户端检测到 Xposed，请自行配置框架的隐藏选项。
